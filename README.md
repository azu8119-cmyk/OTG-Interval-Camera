# OTG Interval Camera 0.2

Samsung S25 / USB UVC. Preview + JPEG into selected folder, interval 1–300 seconds, resolution selection (including 2560×1440 if camera supports), MJPEG or YUYV, USB diagnosis, Picture-in-Picture. Keeps screen awake while activity is visible. No kiosk or touch lock. PiP is not a guaranteed persistent background service. GitHub Actions → Build APK → Artifacts.
