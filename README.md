# OTG Interval Camera (Samsung Galaxy S25) — тестовый исходный проект

**Назначение:** превью стандартной USB/UVC OTG-камеры, выбор папки, разрешения камеры,
интервала 1–300 секунд и последовательная запись JPG; во время работы экран не гаснет.
Есть защита от касаний и режим Android Lock Task / Device Owner для управляемых устройств.

## Возможности

1. При первом старте предлагает выбрать папку посредством Storage Access Framework.
   Выбранная папка сохраняется как URI; доступ запрашивается явно у пользователя.
2. После выбора папки отображает UVC-превью. USB-камера должна поддерживать стандарт UVC,
   USB OTG на телефоне должен быть включён.
3. В правом верхнем углу: ⚙. Настройки: доступные размеры кадров самой камеры,
   поле интервала 1–300 секунд, смена папки и кнопка «Начать интервальную съёмку».
4. После запуска экран принимает только разблокирующий жест: **провести пальцем слева
   направо в нижних 155 dp экрана**. Остальные касания игнорируются. Разблокировка
   управления НЕ прекращает съёмку; остановка — в настройках.
5. `FLAG_KEEP_SCREEN_ON`: пока экран приложения виден, обычный тайм-аут его не выключит.
6. Объявлен `DeviceAdminReceiver` для **опционального** строгого Android Kiosk Mode.
   Если приложение назначено Device Owner, оно делает Lock Task allowlist и отключает
   элементы системной навигации и уведомлений. Из киоска оно выходит при остановке съёмки.
   Без Device Owner можно отдельно включить менее строгий режим «закрепить экран».

## Как собрать APK

1. Установите Android Studio с Android SDK Platform 35 и JDK 17.
2. `File → Open` и выберите папку **OTG_Interval_Camera**.
3. Дождитесь импорта Gradle. В корневом build.gradle.kts версии плагинов зафиксированы: Android Gradle Plugin 8.8.2 и Kotlin 2.2.20; Gradle 8.10.2. В режиме online Gradle загрузит зависимость AUSBC 3.6.0
   с JitPack (требуется Интернет для первого импорта).
4. `Build → Generate Bundle(s) / APK(s) → Generate APK(s)` (в некоторых версиях: `Build Bundle(s) / APK(s) → Build APK(s`).
5. Установите полученный debug APK на Samsung S25; дайте доступ к выбранной папке
   и USB-устройству во всплывающем запросе.

Исходник UVC-движка: <https://github.com/ernestp/AndroidUSBCamera> (Apache-2.0).

## Важное про строгую блокировку

Android НЕ позволяет произвольному обычному приложению надёжно блокировать шторку,
Home, Recents и системную навигацию. Для строгого режима требуется Device Owner
(управляемый телефон) или корпоративные политики Samsung Knox. Предусмотрен
`com.example.otginterval.KioskAdminReceiver`.

**Осторожно:** команда `adb shell dpm set-device-owner
com.example.otginterval/.KioskAdminReceiver` применима только к устройству,
соответствующему ограничениям Android на подготовку Device Owner (часто требуется
новая настройка или factory reset и отсутствие обычных аккаунтов). На личном
телефоне не выполняйте её без понимания последствий. Рекомендуется тестовый телефон.

В обычном режиме применяется только полноэкранное скрытие панелей и блокировка
касаний самим приложением. Пользователь по-прежнему может вызвать системные элементы
некоторыми жестами и кнопками. Физическую кнопку питания приложение не отключает.

## Текущие ограничения тестового проекта

- Проект **не собран в APK и не проверен на конкретном Samsung S25 / USB-камере**;
  точное поведение USB-устройства и API AUSBC 3.6.0 нужно проверить на устройстве.
- Вариант 0.1 использует `CameraFragment` и предполагает активное приложение на
  экране (особенно при Lock Task). **Непрерывная съёмка после сворачивания** не
  реализована: библиотека может закрыть камеру при остановке Activity.
- «Поверх других приложений» в 0.1 достигается фиксацией приложения на экране в
  киоск-режиме, а **не отдельным плавающим оверлеем**. Для настоящего фонового
  USB-захвата понадобится отдельный foreground service, владеющий UVC-соединением.
- При смене разрешения библиотека переподключает UVC; запуск после восстановления
  изображения нужно повторить. Не все размеры гарантированно поддерживаются камерой.
- Интервал — best effort: если камера/файловая система обрабатывает JPEG дольше
  выбранного интервала, кадры пропускаются, а не накладываются друг на друга.
- Не рассчитано на незаметную работу: режим съёмки явно отображается на экране.

## Тестовый план

- Проверьте выдачу USB-разрешения при первом подключении и после переподключения.
- Проверьте JPEG в выбранной папке, имена `OTG_yyyy-MM-dd_HH-mm-ss_SSS.jpg`.
- Проверьте последовательность для 1 / 5 / 300 секунд и переключение разрешений.
- Проверьте жест снизу слева направо и остановку съёмки после разблокировки.
- Проверьте, что экран не гаснет во время работы, и исключения для энергосбережения.
- Для строго киоска — обязательно проверьте механизм выхода до длительного теста.

## Сборка через GitHub Actions без локальной установки Android Studio

В архив включён `.github/workflows/build-apk.yml`. Загрузите содержимое папки
проекта в отдельный репозиторий GitHub и запустите **Actions → Build test APK →
Run workflow**. При успешной онлайн-сборке архив с APK будет доступен в Artifacts.
Это инструкция для самостоятельной сборки; CI здесь не запускался и успех
сборки не подтверждён.
